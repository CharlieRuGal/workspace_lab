# REPOS

> **TL;DR:** Índice de repositorios clonados. Cada repo conserva su propio Git; este workspace solo versiona este archivo.

## Propósito

Esta carpeta reúne el código fuente clonado dentro del workspace. Sirve como índice para localizar cada repositorio antes de trabajar en él.

- El código de cada proyecto se versiona en su propio repositorio Git, no en el workspace.
- `.gitignore` excluye el contenido de `REPOS/`, excepto este `AGENTS.md`.
- No se modifica un repositorio desde aquí sin revisar primero su propio control de versiones.
